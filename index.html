03 · Code

crawler.py 
# 爬取 PTT 八卦板文章標題
import requests
from bs4 import BeautifulSoup
import pandas as pd

def get_ptt_titles(pages=5):
    headers = {'Cookie': 'over18=1'}
    titles = []

    for i in range(pages):
        url = f'https://www.ptt.cc/bbs/Gossiping/index{i}.html'
        res = requests.get(url, headers=headers)
        soup = BeautifulSoup(res.text, 'html.parser')

        for item in soup.select('.r-ent .title a'):
            titles.append(item.text.strip())

    return pd.DataFrame(titles, columns=['title'])

df = get_ptt_titles()
df.to_csv('ptt_titles.csv', index=False)
print(f'共抓取 {len(df)} 篇文章')

06 · Conclusion

結論與心得

本次分析發現，PTT 八卦板近期討論以負面情緒為主（62%）， 關鍵字集中在政治與社會事件。正面討論主要來自娛樂與美食話題。

透過本專題，實際學習了 HTTP 請求、HTML 解析、中文 NLP 斷詞，以及資料視覺化的完整流程， 了解到爬蟲在資料收集上的實用性，以及反爬蟲機制的因應方式。
